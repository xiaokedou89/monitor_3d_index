# 3D 展示管控系统

单场景 3D 交互展示页：以 4 个自下而上堆叠的水平层带（**地域分布层 → 设备分布层 → 应用分布层 → 任务分布层**）展示复杂网络拓扑、层间关联、实时告警与实体配置管理。底部为平面中国地图（含台湾省/港澳、南海诸岛附图、十段线），世界地图背景与中国地图同投影同比例（1:1 地理真实比例）；全部交互（浏览、聚焦、区域展开、点选、告警处置、配置操作）在唯一 3D 场景内完成。

## 功能特性

- **四层拓扑**：地域层（机房/云机房/组织机构 36）→ 设备层（10 类 141）→ 应用层（13 类 113）→ 任务层（6 类多级任务树 155），共 445 实体 / 844 关系
- **分层聚焦**：相机阻尼飞行 + 非聚焦层压暗淡化 + 非聚焦层点击排除 + 缩略图联动；聚焦机位按**可配置俯仰角**生成（默认 45°，早期浅角造成实体重叠严重）
- **键盘视角微调**：聚焦态下 J/K 减小/增大视线夹角、H/L 左右扭头、WASD/QE 前后左右上下平移，步进值可配置（总览态门控禁用）
- **地图布局 A/B**：默认 A 布局（以中国为中心：欧洲最左、美洲最右，1:1 地理比例不压缩），可切换 B 布局（线性经纬度现状），美洲机房连线不再超出观察范围
- **区域对象化**：层/网/子区域支持 3D 点击选中 → 区域详情（摘要/属性/配置=实体列表可过滤检索）+ 缩略图联动高亮 + 矩形框选中突出；布局设置打开时点击区域自动切换配置目标，支持区域位置/配色/透明度定制
- **层间分离**：聚焦某层时，其上方各层整体上移、下方各层下移（垂直距离 0–100 可配置），非目标层大幅透明化，消除遮挡（总览一键还原）
- **区域展开**：密集区域"展开"为浮空子平面（布局预生成防重叠），原位虚线框保持空间指向，收起相机快照还原
- **区域布局配置**：密集分区按实体类型自动分带构成子区域、按比例缩放实体与间距；每层各区域平面尺寸可配置、实体自适应；功能子区域可手动折叠（仅显示活跃实体）；支持保存/命名/应用多个布局预设
- **连线语义**：控制蓝 / 数据黄 / 告警红，关键控制边加粗+流动虚线+脉冲，线宽=流量对数映射（低流量保留对比、高流量/尖峰压缩封顶，避免光晕遮挡全局）；点击连线查看关系详情（两端可跳转）
- **层间关联**：部署于（机房→设备）/运行于（设备→应用）/承载（应用→任务）/隶属（任务树层级），默认隐藏，四档开关（隐藏/两层间/全部/选中实体相关）
- **实时告警与消息中心**：剧本驱动（正常运转/故障演练/攻击告警/跨层故障链），实体闪烁+场景光晕 FX（光晕范围基线已收敛，密集告警不遮挡全局）；左侧消息状态区（4 类计数+时序折线图）+ 动态消息窗体（告警/提示/工单滚动弹出、清空自动隐藏、历史列表模式），告警含详情/处置建议/定位实体/查看连线
- **界面布局（P4）**：左侧消息三区 + 底部中间详情窗口（可缩小停靠/放大上拉）+ 底部右侧实体控制窗口（实体操作/区域批量操作）+ 右上角帮助（连接语义/操作说明）与智能助手（离线问答）
- **设置面板（3 tab）**：⚙ 设置 = 显示设置（风格样式/告警光晕 ×0.4–4、×0–4/泛光 0–0.005 默认 0.0011/连线/视角控制/标签）+ 布局设置（地图布局 A/B/层间分离/区域布局与预设）+ 演示设置（剧本/倍速/暂停/一键导览/层间关联），实时生效 + localStorage 持久化 + 一键恢复默认
- **风格样式模板**：内置 4 套主题（深空科技/青蓝冰川/琥珀暖阳/素净灰阶）+ 自定义样式保存/选择/应用，背景/雾/层平面/地图配色一体化切换
- **实体模型替换管线**：`public/data/models.json` 按实体类型配置 GLB 模型，启动自动加载替换程序化几何体（失败自动回退），操作手册见 docs/06
- **配置管理**：实体详情窗口 3 tab（摘要/属性/配置）+ 实体控制窗口操作（机房启停、设备起停/防火墙配置/管理命令、服务起停/运行参数/数据管理，操作带确认与状态闭环）+ 区域批量操作（批量发送指令/发布消息/同步管理策略）
- **一键演示**：8 步导览脚本化相机路径 + 定时剧本触发

## 快速开始

```bash
npm install
npm run dev            # http://localhost:5173
```

| 命令 | 说明 |
|---|---|
| `npm run build` / `npm run preview` | 生产构建 / 产物验证（:4173） |
| `npm run typecheck` | TS strict 全量类型检查 |
| `npm test` | Vitest 单测（node env，188 例） |
| `npm run e2e` | Playwright E2E（系统 chromium + SwiftShader，19 例全流程，截图存档 `shots/`） |
| `npm run gen:data` | 种子化重新生成演示数据（同 seed 逐字节一致） |
| `npm run fetch:map` | 下载+核验地图 GeoJSON（十段线/台湾/港澳校验，SHA-256 元信息） |
| `npm run sse` | 可选 SSE 演示服务器（`/events` 事件流，默认回放 attack 剧本） |

调试：`?debug=1` 暴露 `window.__sceneDbg` + 性能面板；运行中按 **F3** 开关性能面板。

## 技术栈

原生 Three.js 0.185（WebGL2，单场景，GLTFLoader GLB 模型替换管线）· Vite 8 + TypeScript 5.9 strict · earcut 三角化 · 事件溯源仿真引擎（确定性）· Vitest + Playwright · 零运行时 UI 框架

性能实测（1600×900）：总览 142 draw calls / 13.5 万 tris；设备层聚焦 249 / 13.5 万。

## 地图数据说明

演示用中国地图数据取自 DataV.GeoAtlas（基于自然资源部标准地图数据加工，含台湾省/香港/澳门与十段线要素，下载脚本强制核验）；世界地图背景（Natural Earth）与中国地图采用**同一投影、同一比例（1:1 地理真实比例）**绘制，位置严格一致。**生产环境请替换为自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）发布的标准地图并标注审图号**，本项目不以演示数据代替正式地图成果。

## 浏览器兼容

WebGL2 现代浏览器（Chrome/Edge ≥110、Firefox ≥113、Safari ≥16）。无硬件加速环境自动降级（禁用 bloom、软渲染），功能完整但帧率受限。
